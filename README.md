# Skye

Single-file weather application with animated SVG icons and condition-based theming.

## What it does
Skye shows current weather, a 24-hour hourly strip, and a 7-day forecast using Open-Meteo API (free, no key required). Background surface shifts color based on weather conditions. Animated SVG icons represent each weather state.

## Tech
- HTML / CSS / JavaScript (Vanilla)
- Open-Meteo API for weather data and geocoding
- Open-Meteo Geocoding API for city search
- Satoshi (Fontshare CDN) for body text
- Recoleta (CDN) for weather condition labels

## Run locally
Download or clone the repo. Open index.html in a browser. No build step required.
